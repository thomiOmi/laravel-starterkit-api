# Product Requirements Documents

This directory holds the formal product requirements for the Laravel Starterkit API.

| Document | Description |
|----------|-------------|
| [starterkit-api.md](starterkit-api.md) | Main PRD for the starterkit product (v1 scope) |

## Process

- The main PRD describes the product as a whole. New features get a dedicated PRD file here only when they have product-level scope beyond a single module.
- Requirement IDs referenced in PRDs (AUTH-01, IAM-01, ...) link to test/verification status in `../testing.md` and the execution tracker in `../../TASKS.md`.
- Design decisions behind requirements are recorded in `../adr/`, not inside PRDs.
