# Security Policy

## Supported Versions

This project is pre-1.0. Only the latest release is supported. Always upgrade to the newest tag (see the [releases page](https://github.com/thomiOmi/laravel-starterkit-api/releases)) before reporting an issue.

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub Private Vulnerability Reporting:

[https://github.com/thomiOmi/laravel-starterkit-api/security/advisories](https://github.com/thomiOmi/laravel-starterkit-api/security/advisories)

Include in the report:

- The kit version (tag or commit) you are using.
- A description of the vulnerability and its impact.
- Steps to reproduce, or a minimal proof of concept.
- Any suggested mitigation, if known.

Do not open a public issue or discussion for security problems.

## Response and Disclosure

- Acknowledgement within 7 days of the report.
- Target for a fix within 30 days, depending on severity and complexity.
- Coordinated disclosure: the issue is made public only after a fixed release is available.

## Language

Reports in English are preferred.
