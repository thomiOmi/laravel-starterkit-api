# Phase 1 Quality Foundation - Plan 02: PHPStan Gate Extension and Quality Gates

## Objective

**As a maintainer, I want PHPStan at max level to analyze module test files and the type-coverage gate to count them, so that a quality regression in any module test fails the build fast instead of shipping silently.** This plan extends the already-green QLTY-01/QLTY-02 baseline to module tests (D-11, D-12) and proves the full failing-fast loop (D-08, D-09) with the new contract suite from Plan 01 in scope.

- **Purpose:** The baseline gates are green today; removing the module-test exclude strengthens them without weakening any config (D-11 explicitly permits this - the ban targets lowering level or adding ignores). Type coverage already scans module files, so the new AuthRateLimitTest.php must keep the 100 percent gate - Plan 01 enforced strict_types and typed closures for exactly this reason.
- **Output:** phpstan.neon with the module exclude removed, and three green gate runs: composer types:check, composer test:quality, composer ci:check.

**Artifacts this phase produces:** phpstan.neon (one excludePaths line removed). No runtime code, no new files, no packages.
